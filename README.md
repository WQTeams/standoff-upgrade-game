# Standoff Upgrade Game

A weapon skin upgrade game with login, marketplace, upgrade wheel, and balance system.

## Quick Start

```bash
npm install
npm start
```

Then open `http://localhost:3000`

## Features

- User authentication (login/register)
- Persistent SQLite database
- Marketplace to buy weapon skins
- Upgrade wheel with customizable odds
- Inventory system
- Balance tracking
- Contact form to top up balance
